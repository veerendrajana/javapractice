# Java Interview Questions

## 1. Self Introduction

## 2. Core Java Concepts
1. What is an interface, and how does it work?
2. What is an abstract class?
3. If a class has one abstract method and one non-abstract method, can it work without declaring the class as abstract? Why?
4. Can an abstract class contain both abstract and non-abstract methods?
5. What happens if an abstract class is not declared with the abstract keyword? Will it work? Why?

## 3. Interfaces and Abstraction
1. Suppose you have an interface and declare it as abstract. Will there be any issue?
2. If you declare Method1, Method2, and Method3 as abstract inside an interface, will it work?
3. If an interface has abstract methods A, B, and C, and Method D has a method body, will it work? Where will the implementation of A, B, and C be provided?

## 4. Selenium Basics
1. What is the difference between driver.close() and driver.quit()?
2. You have 10 browser windows open, and you are currently on the last window. How would you close all the other windows while keeping the current window open?
3. What is the difference between getWindowHandle() and getWindowHandles()?
4. Explain the use of getWindowHandle() and getWindowHandles().

## 5. Exception Handling
1. In a try block with multiple catch blocks (ArithmeticException, NullPointerException, StaleElementReferenceException, and Exception), if a StaleElementReferenceException is thrown, which catch block will execute? Why?
2. If a NoSuchElementException is thrown, which catch block will execute?

## 6. Coding Practice
1. Write a Java program to reverse the words in a sentence (not the characters).
